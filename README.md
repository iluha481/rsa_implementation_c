# Реализация алгоритма шифрования RSA на C
Приложение позволяет зашифровать или дешифровать сообщения алгоритмом RSA. Поддерживается как и консольный ввод-вывод, так и файловый.

## Требования
Установленный компилятор GCC

## Компиляция и запуск

Скомпилировать проект:
```sh
gcc -o rsa_main rsa_main.c rsa_encrypt_decrypt.c
```

После чего запустить:

```sh
./rsa_main
```
